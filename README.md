# Neutron releases

Official Windows installers for **Neutron**, a streaming studio built on OBS.

Download the latest version from the **[Releases](https://github.com/gabyto19/neutron-releases/releases/latest)** page (`Neutron Setup <version>.exe`). Neutron checks this page for updates and tells you when a new version is out; it never downloads or installs anything by itself.

Each release lists the installer's SHA-256 checksum, so you can check the file you downloaded.
